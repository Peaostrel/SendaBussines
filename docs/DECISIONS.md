# Decisions

## Stellar Private Payments

Stellar Private Payments are out of scope for this sprint. The team has not decided to include them. Do not build them as part of the SEP-24 deposit, the escrow release, or the optional metrics dashboard.

## Deliverable 3

The metrics dashboard is optional. It depends on an event log that this sprint has not built yet. The sprint can finish without it. Deliverables 1 and 2 do not depend on it.
